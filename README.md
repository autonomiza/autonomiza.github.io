# Autonomiza

Web estática de soluciones digitales para pymes. Publicación autorizada por Iván el15/10/2026: escena continua al desplazarse, luces con interpolación y retrato original sobre gris con marco luminoso.

## Implementación

index.html, escena.css y escena.js componen el recorrido. Un único canvas transforma seis recorridos; las luces avanzan entre muestras por interpolación. Pausa, movimiento reducido y suspensión al ocultarse. calculo.js calcula tiempo dedicado sin prometer ahorro ni enviar datos. fonts.css contiene fuentes locales.

La presentación muestra assets/ivan-retrato-original.jpg sin modificar sus píxeles, mediante una máscara alfa SVG obtenida de una silueta generada; la máscara elimina el fondo blanco. Las escenas generadas de oficina no se usan en la página.

## Validación

Prueba local revisada en escritorio y móvil; cálculo, pausa y preguntas frecuentes. Iván confirma fluidez en portátil tras corregir el avance de las luces y aprueba la presentación sobre gris. Sin nuevas dependencias externas. CNAME, verificación de Google y textos legales conservados.
